什么时候选传统、不选 Gemini-TTS？

传统不是「过时的 Gemini」。IVR、验证码、毫秒停顿要的是 SSML 契约。演戏、双人、标签才用 Gemini 页。各传统页有「独有 ·」样例，Gemini 页有对照样例。

年龄怎么控？三条路径不一样

官方都没有少年/壮年/老年枚举。Gemini 靠提示词；Chirp 只能换说话人；WaveNet 换 A/B/C/D，pitch 只是音高。

业务怎么选型？

先对场景，再进对应引擎页听样例。定价以官方价目为准。

本产品还有、网页 Demo 故意没接的能力

只列 Cloud TTS / Gemini-TTS 自己有、但网页当场做不了的能力。News / Polyglot / Casual 已在 Neural2 页；设备补偿和音量已在 WaveNet 等页。Live、Gemini Batch 是别的产品，见官方资料「相关路径」。
